X(@goan999999)가 올린 게시물을 봤다: "GitHub에 있는 오픈소스 7개가 월 수십~수백 달러짜리 유료 AI 소프트웨어를 그대로 무료로 만들고 있다"는 리스트다. 프로젝트 7개가 나열돼 있고, 각각 왜 대단한지 구체적인 숫자까지 붙어 있었다. 진짜인지 GitHub API와 각 레포 공식 문서를 직접 대조했다 — 그리고 같은 계정의 다른 게시물도 하나 더 봤다.

7개 프로젝트는 모두 실존하고 대부분 대형 레포다. 하지만 ① "유료를 무료로 만든다"는 프레이밍이 틀렸고(코드만 무료, 구동엔 유료 API 키 필요) ② 인용된 성능 수치는 어느 레포 문서에도 없는 창작이며 ③ 7개 중 2개는 같은 회사(TypeSafe) 제품을 서로 다른 프로젝트인 척 넣었고 ④ 같은 계정이 1시간 전 "GitHub에 유출된 OPENAI_API_KEY를 검색해서 공짜로 쓰자"는 명백한 범죄 행위를 권했다.

2. "무료"가 아니다: 공짜인 건 코드뿐이다

핵심 논점: 오픈소스(무료 코드) ≠ 무료 운영. 7개 중 구독료를 실제로 0원으로 만드는 건 사실상 없다.

  • hermes-jev-skills — README 설치 절차가 jev setup-key, 즉 TypeSafe의 Jev API 키를 붙여야 돌아간다. 호출당 과금(문서상 트리아지 1건 $0.00006). 싸긴 해도 무료는 아니다.
  • typesafe-ai/skills — README 첫 줄이 "Agent skills for building with TypeSafe". 범용 스킬 팩이 아니라 TypeSafe System One API를 쓰기 위한 벤더 SDK 스킬이다.
  • OpenHands / MoneyPrinterTurbo / TradingAgents / LibreChat — 전부 BYOK(Bring Your Own Key). Claude·GPT API 키가 있어야 작동한다. 구독료가 사라지는 게 아니라 정액제가 종량제로 바뀔 뿐이고, 많이 쓰면 오히려 더 나온다.
  • CopilotKit/OpenBot — README에 "A free plan is available"이라고 적혀 있다. OSS 코어 + 상용 플랜 구조다.
  • LibreChat은 특히 오해가 크다. 이건 모델이 아니라 UI다. ChatGPT를 대체하는 게 아니라, 여러 API 키를 한 화면에서 쓰게 해주는 껍데기다.

흥미로운 역설 — hermes-jev-skills는 오히려 자기 문서에 훨씬 구체적이고 겸손한 숫자를 적어뒀다. 핸드오프 리콜 37.5%→58.7%, 검색 1회 추가 시 68.3%→75.0%, 메시지당 $0.00002 같은 식이다. 게다가 이 레포는 "핸드오프는 기본적으로 Jev가 판단하지 않는다 — 측정해보니 요약본이 원문 전사보다 리콜이 낮았다"고 자기 기능을 스스로 깎아서 적어놨다. 원문 작성자는 그 정직한 숫자를 버리고 "10배"라는 동그란 숫자를 얹었다.

4. 진짜 위험 신호: 같은 계정의 직전 게시물

같은 계정이 같은 날 약 1시간 전에 올린 글:

원문 요지 번역
"GitHub에서 OPENAI_API_KEY를 검색하면 500만 건이 나온다. 테스트해보니 상당수가 잔액이 남아 작동한다. 이제 Plus 5시간 리셋을 기다릴 필요 없이 무한 토큰이다. 바이브 코딩 개발자 여러분 감사합니다."
  • 이건 팁이 아니라 범죄 교사다. 타인 명의 API 키 사용은 국내 정보통신망법상 무단 침입·부정사용에 해당하고, 미국 기준으로는 CFAA 위반이다.
  • "무한 토큰"은 무료가 아니다. 키를 유출한 개발자 카드에 그대로 청구된다. 남의 돈이다.
  • 실행하면 계정 정지는 기본이고, 유출 키는 이미 스캐너가 긁고 있어 허니팟일 가능성도 높다.
  • 그리고 이 맥락이 앞의 7선 게시물 전체를 다시 읽게 만든다. "유료를 무료로"라는 프레이밍을 쓰는 사람이, 한 시간 전엔 남의 결제수단을 "무료"라고 불렀다.

할 것: 본인 레포의 키 유출 여부를 지금 점검하라. git log -p | grep -i "sk-"로 과거 커밋까지 확인하고, 노출됐다면 즉시 폐기(rotate)한다. 커밋에서 지워도 히스토리에 남는다.

결론

결론은 단순하다. 링크 7개는 저장해둘 만하다. 설명은 버려라. 오픈소스의 가치는 "공짜"가 아니라 "내가 통제한다"는 데 있다 — 데이터가 어디로 가는지, 어떤 모델을 쓸지, 언제 바꿀지. 그걸 '월 20달러 아끼기'로 번역하는 순간, 대부분 API 청구서로 더 내고 끝난다.
