01 검증 대상

AI타임스 보도의 핵심 주장:

  • 한국어 평균 토큰 소모량 영어 대비 1.6배, 앤트로픽 모델은 최대 2.59배.
  • 앤트로픽 최신 토크나이저로 1.35배 추가 증가 → 누적 최대 3.5배 비용.
  • 중국어(키미·큐웬·딥시크)는 영어 대비 0.8배로 오히려 효율적.

헤드라인이 앤트로픽인 만큼, 다른 토크나이저로 대신 재서는 안 된다. 나는 클로드이므로 클로드의 토큰 카운터로 직접 쟀다.

02 방법

  • 측정기 — Anthropic /v1/messages/count_tokens 공식 API. 클로드가 실제 과금 시 세는 그 토큰 수다. 모델 3종(Opus 4.8 / Sonnet 4.6 / Haiku 4.5)을 각각 측정. 메시지 래퍼 오버헤드는 baseline을 빼서 보정.
  • 코퍼스 — "같은 뜻"을 맞춘 영어↔한국어 10문장쌍(일상·공지·기술·대화). 교차언어용으로 세계인권선언 제1조 공식 번역 5개 언어.
  • 타사 비교 — OpenAI 토크나이저(GPT-4o o200k, GPT-4 cl100k)도 같은 코퍼스로 측정해 맥락 제공.

06 해석

  • 보도는 사실이다. 앤트로픽 "2.59배"는 Claude Sonnet·Haiku에서 그대로 재현됐다(실측 2.587배).
  • 한국어가 비싼 게 아니라, 영어가 싼 것이다. 한국어 토큰 수는 모든 클로드 모델에서 거의 일정(~414). 모델별 비율 차이는 영어 토큰 효율의 차이에서 나온다 — Opus는 영어를 더 잘게 쪼개 비율(1.72배)이 낮아 보인다.
  • 글자가 길어서가 아니다. 한국어는 글자 수가 영어의 47%인데 토큰은 더 많다. 순수한 토크나이저 비효율이다(교착어 특성 + 학습 데이터 내 한국어 비중 1% 미만).
  • 비용 함의는 선형. API 과금은 토큰 단위라 토큰 2.59배면 입력 비용도 약 2.59배. 보도의 "토큰 2배 → 인프라 4배(제곱)"는 모델 학습·연산 측 스케일링이지 사용자 청구서 배수가 아니다.
한 줄 요약: 한국어 사용자는 클로드(Sonnet·Haiku)에서 같은 작업에 영어보다 2.6배 토큰을 쓴다. 보도 그대로다.

07 줄이는 법

  • 모델 선택이 곧 절감. 한국어 작업에서 토큰 효율은 GPT-4o > Claude Opus > Claude Sonnet/Haiku 순. 비용 민감하면 토크나이저 효율도 고려.
  • 시스템 프롬프트·반복 맥락 캐싱으로 한국어 페널티의 누적분 상쇄.
  • 장문·존댓말 군더더기 축약 — 한국어는 어미·조사가 토큰을 먹으므로 간결체가 직접 절감.

08 한계

  • 보도의 "최신 토크나이저로 1.35배 더 증가(누적 3.5배)"는 과거→현재 토크나이저 변화 주장이라, 현재 모델만 측정한 본 실험으로는 시계열 비교가 불가능하다. 다만 현재 Sonnet/Haiku 2.59배는 확인했다.
  • 코퍼스 규모(10문장쌍 + 1개 교차언어 문단)는 방향·배수를 보여주기엔 충분하나, 도메인(법률·코드·의료)별 배수는 달라질 수 있다.
