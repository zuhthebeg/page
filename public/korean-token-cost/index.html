한국어는 정말 토큰을 더 먹는가

"한국어 AI 사용료가 영어보다 1.6배, 앤트로픽은 2.59배 비싸다"는 AI타임스 보도를 실제 토크나이저로 직접 측정해 검증했다.

01 검증 대상

기사 주장 요약:

  • 한국어 평균 토큰 소모량 영어 대비 1.6배, 앤트로픽 모델 최대 2.59배.
  • 앤트로픽 최신 토크나이저로 1.35배 추가 증가 → 누적 최대 3.5배 비용.
  • 중국어(키미·큐웬·딥시크)는 영어 대비 0.8배로 오히려 효율적.
  • 원인: 한국어의 교착어 특성(조사·어미 결합) + 토크나이저 학습 데이터에서 한국어 비중 1% 미만.

이 중 토큰 소모 배수는 모델 API에 직접 텍스트를 넣어 토크나이저로 셀 수 있다. 직접 쟀다.

02 방법

  • 토크나이저 — OpenAI 공식 BPE 2종을 그대로 사용. o200k_base(GPT-4o·4.1·o-시리즈, 최신) / cl100k_base(GPT-4·3.5-turbo, 구세대). 라이브러리: gpt-tokenizer (vocab 동일).
  • 코퍼스 — "같은 뜻"을 맞춘 EN↔KO 10문장쌍(일상·공지·기술·대화 혼합)을 직접 작성. 교차언어 비교용으로 세계인권선언 제1조의 공식 번역 5개 언어(EN·KO·JA·ZH·ES) 추가.
  • 지표 — 의미가 동일한 텍스트의 토큰 수 비율(영어=1.0), 그리고 글자 수·토큰/글자.

한계: 앤트로픽 Claude의 최신 토크나이저는 비공개라 API 키 없이 직접 측정 불가. 대신 같은 세대 BPE인 cl100k가 그 수준을 대리한다(아래 참조).

05 해석

  • 기사 주장은 사실이다. 같은 뜻의 한국어가 영어보다 토큰을 더 먹는다 — 측정값 1.42×(GPT-4o)~2.49×(GPT-4).
  • 배수는 토크나이저 세대에 강하게 의존한다. 구세대 cl100k에선 2.5×지만, 더 많은 다국어 데이터로 학습한 최신 o200k에선 1.4×로 거의 절반. 기사의 "앤트로픽 2.59×"는 cl100k급 구형 토크나이저 수준과 일치한다.
  • "한글이 길어서"가 아니다. 한국어는 글자 수가 영어의 47%인데 토큰은 더 많다. 순수하게 토크나이저가 한글 음절·조사·어미를 잘게 분해하는 비효율이다.
  • 비용 함의는 선형이 기본. API 과금은 토큰 단위라 토큰 1.4배면 입력 비용도 약 1.4배. 기사의 "토큰 2배 → 인프라 4배(제곱)"는 모델 학습·연산 측면의 스케일링이지, 사용자 API 청구서의 배수가 아니다 — 이 구분은 유의해야 한다.
한 줄 요약: 한국어 사용자는 같은 작업에 토큰을 1.4~2.5배 더 쓴다. 최신 모델일수록 격차가 줄지만 여전히 영어가 가장 싸다.

06 줄이는 법 (실무)

  • 최신 모델 토크나이저를 쓴다. 같은 한국어라도 o200k(GPT-4o)가 cl100k(GPT-4)보다 토큰이 거의 절반.
  • 출력이 길어지는 작업은 영어로 사고시키고 마지막에 번역하면 토큰을 아낄 수 있다(품질 트레이드오프 존재).
  • 시스템 프롬프트·반복 맥락은 캐싱. 프롬프트 캐시가 적용되면 한국어 페널티의 누적분을 상쇄한다.
  • 불필요한 장문·존댓말 군더더기 축약 — 한국어는 어미·조사가 토큰을 먹으므로 간결체가 직접 절감된다.

07 한계

  • 앤트로픽 Claude 최신 토크나이저는 비공개라 직접 측정하지 못했다(API 키 부재). cl100k가 동세대 대리값.
  • 코퍼스 규모(10문장쌍 + 1개 교차언어 문단)는 방향과 배수를 보여주기엔 충분하나, 도메인(법률·코드·의료)별로 배수는 달라질 수 있다.
  • 번역은 의미를 맞췄지만 길이는 언어마다 자연히 달라진다 — 그 변동까지 포함한 "실사용 배수"가 위 수치다.

재현: gpt-tokenizer로 동일 코퍼스를 o200k_base / cl100k_base 인코딩해 토큰 길이를 합산했다.
