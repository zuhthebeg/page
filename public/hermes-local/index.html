Hermes를 다른 PC에 깔 수 있나

Nous Research의 오픈웨이트 Hermes 라인업을 조사하고, 우리(cocy) 환경 기준으로 다른 PC에 로컬 셋업이 현실적인지 VRAM 티어별로 판정한다. 결론부터: 12GB면 14B, 24GB면 4.3 36B가 실용선이다.

대상 Hermes 4 (14B/70B/405B) · Hermes 4.3 (36B) 제작 Nous Research 분류 오픈웨이트 · 무검열/중립정렬 작성 2026-06-21
셋업 타당성
다른 PC가 24GB VRAM(RTX 3090/4090)이면 Hermes 4.3 36B 로컬 셋업 추천. 12GB면 Hermes 4 14B가 한계선.
가능조건부 · GPU VRAM 의존
12GB → 14B OK 24GB → 36B OK 70B+ → 서버급 GGUF · Ollama 한 줄 실행 라이선스 베이스 의존

01 Hermes가 뭐고 왜 보나

Hermes는 Nous Research가 내는 오픈웨이트 LLM 시리즈다. 상용 폐쇄모델(ChatGPT/Claude)과 달리 가중치를 직접 받아 자기 하드웨어에서 돌릴 수 있고, 두 가지 차별점이 핵심이다.

  • 중립 정렬 · 최소 거부 — 회사 정책으로 답을 막는 대신 "사용자 가치에 정렬"을 지향. Hermes 4.3은 RefusalBench(불필요한 거부 측정)에서 오픈·폐쇄 통틀어 SOTA를 주장. 캐릭터/롤플레이/제약 적은 어시스턴트에 강점.
  • 하이브리드 추론 — <think>...</think> 태그로 추론 모드를 켜고 끈다. 단순 질의는 빠르게, 복잡한 건 사고사슬을 펼친다.

우리가 보는 이유는 명확하다. llm.cocy.io는 현재 OpenAI/Claude/Gemini 같은 과금·외부 경로에 묶여 있다. 무검열·중립 모델을 로컬로 두면 (1) 캐릭터/게임 NPC 대화처럼 정책 거부가 거슬리는 용도, (2) 과금 없는 로컬 백엔드 옵션, (3) 프라이버시가 필요한 작업을 우리 GPU에서 처리할 수 있다.

02 라인업 — 무엇을 깔 수 있나

현재 받을 수 있는 주요 가중치는 네 가지다. 같은 Hermes라도 베이스 모델이 다 다르다(라이선스가 거기서 갈린다).

모델베이스파라미터컨텍스트출시성격
Hermes 4 14BQwen314B~128K2025-08가성비 소형
Hermes 4.3 36BSeed-OSS-36B36B최대 512K2025-12로컬 플래그십
Hermes 4 70BLlama 3.170B~128K2025-08고성능
Hermes 4 405BLlama 3.1405B~128K2025-08프런티어급

주목할 건 Hermes 4.3 36B다. Nous가 "소비자 로컬 추론용 최적 형태"로 내놓은 모델로, 파라미터 절반(36B)으로 Hermes 4 70B에 근접하는 성능을 주장한다. 컨텍스트도 최대 512K. 즉 "로컬에 깔 거면 70B 무리하지 말고 4.3 36B"가 Nous의 공식 권장이다.

메모: Hermes 4.3은 Nous의 Psyche 분산 학습 네트워크(DisTrO 옵티마이저, Solana 합의)로 학습된 첫 프로덕션 모델이다. 우리 셋업과 직접 상관은 없지만 "탈중앙 학습으로 프런티어 모델 만든다"는 방향이라 추적 가치 있음.

03 다른 PC 셋업 타당성 — VRAM이 전부다

로컬 LLM은 사실상 GPU VRAM 용량 싸움이다. GGUF 양자화(Q4_K_M, 품질/크기 스윗스폿)로 받았을 때 모델이 VRAM에 들어가면 빠르고, 넘치면 CPU로 흘러(offload) 급격히 느려진다. 실측 파일 크기 기준:

모델Q4_K_M 크기풀 GPU 권장 VRAM*판정
Hermes 4 14B≈ 9.0 GB12 GB소비자 GPU OK
Hermes 4.3 36B≈ 21.8 GB24 GB3090/4090급 OK
Hermes 4 70B≈ 42 GB48 GB (2×24)멀티GPU/대용량
Hermes 4 405B≈ 230 GB+멀티 H100/A100서버·클라우드 전용

*가중치 + 컨텍스트 KV 캐시 + 여유분 포함 실사용 기준. 컨텍스트를 길게 잡으면 VRAM이 더 든다.

우리 환경(RTX 3080 Ti · 12GB) 기준

  • Hermes 4 14B (Q4) — 실용 한계선. 9GB라 12GB에 들어가지만, 컨텍스트를 4~8K 정도로 잡아야 안전. 길게 쓰려면 Q3로 더 줄이거나 일부 CPU offload(느려짐). 우리 로컬 LLM 코딩 보고서에서 짚은 "12GB 현실"과 동일.
  • Hermes 4.3 36B — 12GB로는 무리. 21.8GB라 절반 이상 CPU로 흘러 토큰/초가 뚝 떨어진다. "되긴 되는데 쓸만하진 않은" 구간.

그래서 "다른 PC"는 이렇게 보면 된다

  • 그 PC가 24GB(RTX 3090/4090)다 → 망설일 것 없음. Hermes 4.3 36B Q4 풀 GPU로 쾌적. 이게 베스트 시나리오.
  • 16GB(4060 Ti 16G/4080 등)다 → 14B는 여유, 36B는 Q3/Q4 + 약간 offload로 "쓸만" 정도.
  • 12GB 이하다 → Hermes 4 14B까지. 36B는 비추.
  • GPU 없음(CPU만) → 14B도 토큰/초가 답답함. 데모는 가능, 실사용은 비추.

04 어떻게 까나 — 실행 스택

전부 GGUF가 풀려 있어서 셋업 난이도는 낮다. 쉬운 순서:

  • Ollama (가장 쉬움) — 설치 후 한 줄. ollama run hermes... 식으로 GGUF 자동 다운로드+서빙. OpenAI 호환 API(localhost:11434)라 우리 스택에 바로 붙는다. CPU offload 자동.
  • LM Studio (GUI) — 클릭으로 모델 받고 채팅/서버. 비개발자 친화적, 컨텍스트 길이 슬라이더 주의(기본 4K 함정).
  • llama.cpp (로우레벨) — 직접 빌드, -ngl 로 GPU 레이어 수 조절해 offload 미세제어. 최대 성능/제어.
  • vLLM (서버/배치) — 처리량 최강이지만 보통 풀 GPU(비양자화 or AWQ) 가정. 12~24GB 단일 소비자 GPU엔 과함.
우리 권장 경로: 다른 PC에 Ollama 깔고 → 24GB면 Hermes 4.3 36B, 12GB면 Hermes 4 14B → OpenAI 호환 엔드포인트를 llm.cocy.io에서 한 모델로 등록. 기존 라우팅(gpt/claude/gemini 경로) 옆에 "hermes-local" 추가하는 그림.

05 라이선스 — 상업 전에 확인할 것

Hermes "코드"(hermes-agent 등)는 MIT지만, 가중치 라이선스는 베이스 모델을 상속한다. cocy 서비스에 쓰려면 상업 가능 여부를 모델별로 확인해야 한다.

모델베이스 라이선스(확인 대상)상업 사용
Hermes 4 14BQwen3 → Apache 2.0대체로 자유
Hermes 4.3 36BSeed-OSS-36B (ByteDance Seed)HF에서 확인 필요
Hermes 4 70B / 405BLlama 3.1 Community License월 7억 MAU 미만 OK

우리 규모(상업 사용·소규모)에선 14B(Apache)와 70B/405B(Llama Community, MAU 한참 미만)는 문제없음. 4.3 36B만 Seed-OSS 베이스 라이선스를 HF 모델카드에서 한 번 확인하고 가면 된다.

06 cocy 활용처 — 깔면 뭐 하나

  • 게임/캐릭터 NPC 대화 — 무검열·중립정렬이라 캐릭터 톤 제약이 적다. 고스톱 NPC, 조커런 같은 게임의 동적 대사/힌트에 로컬로.
  • llm.cocy.io 로컬 백엔드 옵션 — 과금 없는 "hermes-local" 모델 추가. PC 켜져 있을 때만 동작하는 보조 경로(터널 경유, TTS/STT 패턴과 동일).
  • 로컬 에이전트 코딩 보조 — 작은 모델 + 좋은 하니스 전략(로컬 LLM 코딩 보고서 참조). 36B면 보조 작업엔 충분.
  • 프라이버시 작업 — 외부로 못 보내는 데이터 가공/요약을 우리 GPU에서.

07 결론 · 다음 액션

"다른 PC에 깔 수 있나" → 그 PC의 GPU VRAM만 보면 답이 나온다.

  • 24GB(3090/4090) → Hermes 4.3 36B로 가라. Nous 공식 권장 + 70B 근접 성능 + 우리한테 최적.
  • 12~16GB → Hermes 4 14B. 안정적, 가볍다.
  • 둘 다 Ollama 한 줄이면 OpenAI 호환 서버까지 끝. llm.cocy.io에 모델 하나 추가하는 작업만 남는다.

다음 단계 제안: (1) 그 PC의 GPU/VRAM 스펙 확정 → (2) Ollama로 해당 사이즈 Hermes 받아 토큰/초·품질 실측 → (3) 쓸만하면 터널+llm.cocy.io 라우팅에 "hermes-local" 등록. PC 스펙만 알려주면 1~3 바로 진행한다.
