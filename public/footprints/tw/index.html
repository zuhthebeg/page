01如何取得時間軸檔案

  1. Android（推薦） — 手機設定 → 位置 → 定位服務 → 時間軸 → 匯出時間軸資料。把存下的 Timeline.json 拖進來即可。
  2. iPhone — Google 地圖 App → 個人頭像 → 設定 → 個人內容 → 匯出時間軸資料。
  3. Google Takeout（舊紀錄用） — takeout.google.com 的「位置紀錄（時間軸）」。請使用 Records.json 或按月的 Semantic Location History JSON — 不是 Settings.json。

⚠️ 2024 年起 Google 把時間軸只存在你的手機裡。所以「用 Google 登入自動匯入」在設計上就不可能（沒有官方 API）— 也正因如此，這個頁面才能在完全沒有伺服器的情況下處理你的檔案。
