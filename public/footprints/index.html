01타임라인 파일 받는 법

  1. 안드로이드 (추천) — 폰 설정 → 위치 → 위치 서비스 → 타임라인 → 타임라인 데이터 내보내기. 저장된 Timeline.json을 그대로 여기에 놓으면 됩니다.
  2. 아이폰 — 구글지도 앱 → 프로필 사진 → 설정 → 개인 콘텐츠 → 타임라인 데이터 내보내기.
  3. Google Takeout (예전 기록용) — takeout.google.com의 "위치 기록(Timeline)". 단, 2024년 이후 기록은 여기 없을 수 있고, Settings.json이 아니라 Records.json / Semantic Location History 월별 JSON을 넣어야 합니다.

⚠️ 2024년부터 구글이 타임라인을 휴대폰 안에만 저장하도록 바꿨습니다. 그래서 구글 로그인으로 자동으로 가져오는 것은 구글 정책상 불가능하고(공식 API 없음), 최신 기록은 반드시 폰에서 내보내야 합니다 — 대신 그 덕에 이 페이지도 여러분의 파일을 서버 없이 처리할 수 있는 거죠.

02프라이버시 — 설계로 보장

📵 업로드 없음이 페이지에는 위치 데이터를 받는 서버 자체가 없습니다. 파싱·렌더링·영상 생성 전부 브라우저에서 일어납니다.
🗺️ 유일한 네트워크: 지도 타일배경 지도를 CARTO에서 받아옵니다. 이때 화면에 보이는 지역의 타일 번호가 전송됩니다 — 그 이상은 없습니다.
🗑️ 흔적 없음탭을 닫으면 끝. 쿠키에도 저장소에도 위치 데이터를 남기지 않습니다.
🔍 검증 가능난독화 없는 순수 JS 한 파일입니다. 개발자 도구로 직접 확인할 수 있어요.
