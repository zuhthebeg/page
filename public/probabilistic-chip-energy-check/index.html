확률칩이 GPU보다 에너지를 1만 배 덜 썼을까?

난수 회로는 실제로 측정했다. 하지만 ‘1만 배’는 완성 칩을 GPU와 나란히 돌려 잰 수치가 아니다.

2026-11-28 · 논문 그림 1·Methods·공개 저장소 대조 · 독립 재실험 없음

판정: 논문에 약 1만 배가 나온다. 이진화 Fashion-MNIST에서 미래 칩이 이미지 한 장을 생성할 때의 에너지 추정치다.

‘GPU가 곧 필요 없어질 것’이나 ‘이미지·영상 생성 전체가 1만 배 효율적’이라는 결론은 이 연구로 뒷받침되지 않는다.

1. 실측한 것과 계산한 것

  • 실측: 트랜지스터 기반 난수 비트 생성 회로. 논문은 실제 확률칩에서 얻은 난수 회로 측정값을 사용했다.
  • 시뮬레이션: 연구진은 GPU 위에서 새 칩 구조를 모사하고 모델을 훈련·평가했다. 이미지 품질은 FID로 비교했다. 완성 확률칩에서 만든 이미지의 품질을 잰 것이 아니다.
  • 에너지 추정: 확률칩 쪽은 셀 업데이트 횟수와 셀당 에너지의 물리 모델을 사용했다. 난수 회로 측정값 외에도 바이어스·배선·클록의 모델링이 들어간다. GPU 쪽도 모델의 FLOP 수를 제조사 사양의 FLOP/J로 나눈 값이다. 연구진은 이 GPU 계산이 실제 소비를 과소평가한다고 설명한다.

2. ‘GPU와 동급’의 범위

그림 1의 비교는 흑백 의류 데이터셋 Fashion-MNIST를 이진화한 벤치마크다. DTM은 에너지 기반 모델(EBM)을 2~8단 연결하고, GPU 쪽은 VAE·GAN·여러 단계 수의 DDPM을 비교 대상으로 삼았다. 비슷한 FID를 내는 구간을 비교한 것이지, 동일한 모델을 옮겨 같은 응답 시간이나 처리량을 달성했다는 뜻은 아니다. 학습·데이터센터 전력·고해상도 텍스트→이미지·영상·LLM으로 일반화할 근거도 없다.

논문의 CIFAR-10 실험도 별개다. 전통적 GAN과 비슷한 성능을 훨씬 작은 결정론적 신경망과 DTM 조합으로 냈다는 결과이지, CIFAR-10에서도 1만 배 에너지 절약을 실측했다는 뜻이 아니다. 논문은 EBM 크기와 연결 수를 더 늘려도 성능 개선이 어느 지점에서 멈췄다고 보고한다.

3. 왜 볼 만한가

확산계 모델의 역과정에는 확률분포에서 샘플을 뽑는 일이 반복된다. 연구진은 트랜지스터 회로의 물리적 랜덤성을 이용해 그 샘플링을 효율적으로 처리하고, 각 단계에서 더 큰 변화를 표현할 수 있도록 EBM을 연결했다. 특정 연산을 훨씬 싸게 할 가능성이 핵심이다. 다음에 볼 증거는 완성 칩의 벽전력·지연·처리량을 같은 품질 조건에서 GPU와 나란히 잰 결과다.
