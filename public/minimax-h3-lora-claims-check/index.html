MiniMax H3용 커뮤니티 LoRA 홍보글을 문서와 파일 메타데이터로 확인했다. 파일은 실제로 있지만, 작은 용량이 저사양 실행·품질·자유로운 이용 권리를 보증하지는 않는다.

2026-11-22 KST 확인 · 문서 기반 조사 · 설치·추론·가중치 다운로드 없음

판정: 추가 가중치는 실재. “8~16GB에서 누구나 무료로”는 조건 누락.

원문이 가리킨 파일은 620,977,128 bytes ≈ 0.621GB. 전체 모델이 아닌 LoRA 추가 가중치다. 원본 H3의 생성기·텍스트 인코더·영상/오디오 VAE는 별도로 필요하다.

대한민국은 공식 H3 Community License의 제외 지역이다. “완전 오픈소스·누구나 자유 이용”이라고 요약하기 어렵다.

범위: 원문은 성인 영상 생성용 파생 가중치를 홍보한다. 이 글은 비노출 기술·권리 팩트체크이며 해당 파생 모델의 다운로드 링크·제작법·예시 이미지는 제공하지 않는다. 생성 품질이나 학습 자료의 권리 확보를 검증한 글이 아니다.

주장 판별메모리라이선스남은 확인출처

01 / 실제 파일과 홍보 주장을 나눈다

NFT_Chen의 2026-11-21 17:54 KST 게시물은 H3에 덧붙이는 LoRA를 소개하며 “약 1,000개 영상·40시간 이상 학습·0.62GB·8~16GB 실행·완전 오픈소스 무료”를 주장한다. 원문 텍스트는 읽기 전용 FxTwitter 응답에서 확인했다. [1]

약 1,000개·40시간 이상 학습이 조사에서는 학습 로그·데이터 명세·권리 증빙을 확보하지 못했다.게시자 주장. 거짓으로 입증한 것도 아님.
8~16GB에서 실행게시물에는 양자화 언급이 있지만, 정확한 파일 조합·해상도·프레임 수·시스템 RAM·오프로딩·peak VRAM·소요시간 로그가 없다.조건부 가능성을 배제하지 않음. 재현 가능한 최소 사양으로 검증하지 못함.
실사·일관성 크게 개선고정 입력·동일 조건의 독립 비교 시험을 하지 않았다.미검증. 홍보 예시만으로 일반화하지 않음.
완전 오픈소스·무료H3는 Apache/MIT가 아닌 지역·사용 제한이 있는 Community License. 공식 전체 시스템 중 비공개 모듈도 있다.제약을 생략한 표현. 공개 가중치와 무제한 권리는 다름.

02 / 0.62GB 옆에서 빠진 것들

LoRA는 기반 모델을 대체하는 독립 실행 모델이 아니다. H3 공식 문서는 33B 생성 Transformer와 Qwen3-VL-32B 기반 인코더, 별도 영상·오디오 VAE를 설명한다. [2]

정확한 index 값은 생성기 66,280,430,144 bytes, 인코더 66,714,780,128 bytes다. 둘만 약 132.995GB지만, 이것을 “항상 133GB VRAM이 필요하다”로 읽어도 틀린다. 디스크 가중치 크기와 실행 peak 메모리는 다른 값이다. [3]

공식은 생성기의 약 13B AdaLN 관련 파라미터를 사전 계산·캐시해 추론 전용 배치에서 로드하지 않을 수 있다고 설명한다. 양자화·pruning·CPU 오프로딩은 가중치 상주량을 바꾼다. 반면 영상 해상도·길이·프레임·배치·attention·VAE 디코딩은 작업 메모리를 늘린다. 작은 LoRA 하나 또는 양자화 생성기 하나의 크기로 전체 예산을 대신할 수 없다.

따라서 8~16GB 실행 주장을 평가하려면 기반 파일 revision, 인코더·VAE 구성, backend 버전, RAM·오프로딩 조건, 실제 peak VRAM과 전체 지연이 함께 있어야 한다. 이번에는 그 실행 시험을 하지 않았고 소비자 GPU의 속도·최소 RAM을 보장하지 않는다.

H3 영상 모델과 H3 Image도 구분해야 한다

인용 게시물에 연결된 앞선 글은 H3 Image의 4K 이미지 생성 이야기다. 이번 대상은 H3 영상 모델의 추가 가중치다. 이미지 모델의 파일 크기·6스텝·4K 사양을 영상 모델의 실행 증거로 가져오면 안 된다. 영상 H3의 공식 설명은 Base 768p, 전체 시스템 최대 2K·15초이며 모듈과 배포 범위도 다르다. [2]

03 / 한국에서는 권리 확인이 먼저다

고정 revision의 MiniMax H3 Community License Agreement(2026-08-02)는 I.5에서 EU·영국·대한민국·미국을 Excluded Territories로 정의한다. II는 허용 지역 안에서만 권리를 부여하고, V.4는 그 밖에서 모델 및 출력의 사용 등을 허가하지 않는다고 명시한다. 제외 지역의 배포 희망자에게는 별도 허가 문의를 안내한다. 개인 연구라는 이유의 자동 면제는 이 문서에서 확인하지 못했다. 법률 자문은 아니다. [4]

“Excluded Territories” means the European Union, the United Kingdom, the Republic of Korea and the United States of America.
  • 파생 가중치도 확인 대상: 라이선스는 Model Derivatives를 별도로 정의한다. 커뮤니티가 변환·미세조정했다는 이유만으로 기반 모델의 조건이 사라진다고 볼 수 없다.
  • 상업 조건: 적용 지역 안에서도 상업 제품·서비스 연 매출이 2,000만 달러를 초과하면 사전 서면 허가가 필요하고, 상업 UI에 MiniMax H3 표시 의무가 있다. 이는 이번 영상 H3 문서의 조건이며 H3 Image 조건과 혼동하지 않는다.
  • 공개와 무제한의 차이: HF API는 공식 H3와 작성자 컬렉션을 license:other로 표시한다. 재배포·지역·허용 용도와 별개로 “파일이 무료”만 강조해서는 안 된다.
  • 동의·자료 출처: 영상이 공개돼 있다는 사실은 학습·재배포 허가나 출연자의 합성 이용 동의를 증명하지 않는다. 이번 조사에서 해당 학습 자료의 권리 증빙은 확보하지 못했다. 미확인은 곧 위법 확정이라는 뜻도 아니다.
  • 안전 의무: AUP에는 미성년자 위해, 안전장치 우회, 무단 사칭과 제3자 권리 침해 등에 대한 제한이 있다. 구체적 서비스 적법성·동의·권리 검토는 별도로 필요하다.

“전부 로컬”이라는 표현도 조건부다

공식 H3는 Context-IR을 호스팅 전처리 시스템이라고 설명하고, 해당 모듈과 2K 재생성 모듈은 이 공개 릴리스에 포함되지 않는다고 적는다. 공식 Full 2K 경로에는 API가 쓰인다. Base만 로컬로 돌리는 경로와 구분해야 하며, 로컬 ComfyUI 화면이라는 이유로 입력이 외부 전송되지 않는다고 가정하면 안 된다. [2]

클라우드 GPU·호스팅 API는 별도 비용과 서비스 정책 대상이다. 무료 다운로드는 무료 전력·하드웨어·GPU 대여·API를 뜻하지 않는다.

04 / 확인한 것보다 크게 말하지 않는다

확인: 원문 텍스트, 저장소·파일 존재와 메타데이터, 공식 모델 구조·가중치 index, 지역·상업·AUP 조건. 미확인: 학습량·시간·데이터 권리, 파생 모델 품질, 양자화 loader 조합, 8~16GB peak 메모리, 생성 시간, 한국어 품질, 실제 실행.

최종 결론

작은 추가 파일이 있다는 이야기는 사실이다. 그러나 “0.62GB짜리 전체 모델”, “8GB 카드에서 품질 보장”, “한국에서도 무제한 무료”라는 결론은 근거가 없다. 그렇다고 저메모리 실행 자체가 불가능하다고 증명한 것도 아니다. 지금 내릴 수 있는 판단은 파일 크기는 확인, 하드웨어·품질은 미검증, 이용 권리는 제한적이다.

노출 이미지·영상·생성 지침 없이 기술·권리 주장만 다뤘다. 페이지는 기존 사이트의 GTM 분석을 사용한다.
