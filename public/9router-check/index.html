01 검증한 주장

원문(스페인어, @alextalksai, 2026-09-11, 2.5만 뷰): "누군가 GitHub에 Claude Code를 완전 무료로 영원히 쓸 수 있게 해주는 리포를 올렸다. 검은 마법이 아니다 — 트래픽을 DeepSeek·Kimi 같은 무료 제공자 10곳으로 자동 리다이렉트한다. 설정 5분. 지금 쓰는 개발자 2만+." 트윗 본문엔 정작 리포 이름이 없었다 — 그래서 먼저 실체부터 찾아야 했다.

GitHub 검색으로 특정한 실물: decolua/9router. 설명과 작동 방식이 트윗 내용과 정확히 일치하는 걸 확인했다.

02 실측 — 직접 설치·구동

말로만 읽고 판단하지 않았다. 로컬 환경에 실제로 설치해서 확인한 것들:

  • 리포 실체 — 2026-01-05 생성, 어제(9/10)도 푸시됨. ⭐28,413 — 트윗의 "2만+ 개발자" 주장과 대략 부합.
  • 설치 — npm install -g 9router. postinstall 스크립트를 실행 전에 직접 읽었고, better-sqlite3 런타임 캐싱뿐 — 수상한 동작 없음.
  • 구동 — 로컬 HTTP 서버(localhost:20128)가 정상 기동, Next.js 기반, OpenAI-호환 API로 응답 확인.
  • 작동 원리 — Claude Code·Codex·Cursor 등이 이미 공식 지원하는 ANTHROPIC_BASE_URL 같은 커스텀 엔드포인트 스위치를 이 로컬 서버로 돌리는 방식. 요청 포맷을 OpenAI↔Claude로 번역하고, 구독 → 저가 → 무료 순으로 자동 폴백한다.

참고로 최근에 검토했던 다른 "무료로 쓰기" 류 툴(GPT-6 Astra용 프록시)은 api.anthropic.com을 사칭하는 자체 CA로 TLS를 가로채는 방식이라 거부했었다. 9Router는 그거랑 다르다 — 공식으로 지원되는 base-URL 교체 방식이라 CA 신뢰 같은 걸 요구하지 않는다. 이 부분은 설계가 안전하다.

03 "완전 무료 영원히" — 실제로는?

여기가 트윗과 실체가 갈리는 지점이다. README가 직접 나열한 무료 경로들을 그대로 옮긴다:

무료 경로실제 한도판정
Kiro AI월 ~50 크레딧(신규 계정 첫 30일 +500)한도 있음 △
OpenCode Free무료 모델 목록이 수시로 변동, 일부는 한시 프로모션불안정 △
Vertex AI신규 가입 $300 1회성 크레딧소진되면 끝 △
iFlow · Qwen Code · Gemini CLI2026년에 무료 티어 전부 단종됨이미 끊김 ✗

마지막 줄은 9Router 자신의 README가 직접 명시한 내용이다 — "무료 제공자가 영원하지 않다"는 증거를 스스로 갖고 있는 셈.

요지: "완전 무료·영원히"가 아니라 "구독 한도를 다 쓸 때까지 아껴 쓰고, 그다음은 저가·한시 무료로 버티는 라우터"다. 실제로 돈을 아예 안 쓰게 해주는 게 아니라, 있는 한도(구독)를 낭비 없이 쓰고 무료/저가로 폴백해서 지출을 늦추고 줄여주는 도구다. 부가로 tool_result 압축(RTK)으로 토큰 20~40% 절감도 따라온다 — 이건 진짜 실익.

04 우리(OpenClaw/cocy.io) 스택에 주는 시사점

  • 같은 문제를 이미 우리가 풀어놨다. llm.cocy.io(Worker) + llm-proxy가 Claude CLI·Codex CLI 구독 경로를 하나의 게이트웨이로 묶어 쓰는 구조라, "하나의 하네스에서 여러 프로바이더 섞어 쓰기"라는 9Router의 핵심 가치는 우리 인프라로 이미 확보돼 있음.
  • RTK 토큰 압축은 참고할 만하다. tool_result(grep·git diff·ls 출력)를 자동 압축해 20~40% 절감한다는 아이디어는 별도로 검토해볼 가치가 있음 — 단, 이전에 검토한 Headroom처럼 "코딩 에이전트 워크로드엔 효과가 작을 수 있다"는 동일한 함정을 의심해야 함.
  • 무료 티어 체이닝은 우리 운영 원칙과 안 맞음. "유료 API 회피"는 우리도 지향하는 방향이지만, 단종 위험이 있는 외부 무료 티어에 프로덕션 워크플로를 의존시키는 건 리스크 쪽이 더 큼 — 실험/개인용으로는 흥미롭지만 cocy.io 운영 파이프라인에 끌어들일 이유는 없음.

05 결론

9Router는 실존하고, 실제로 작동하고, 설계도 안전한 진짜 도구다. 여기까진 트윗이 맞다. 하지만 "완전 무료로 영원히"는 바이럴을 위한 과장이다 — 무료 경로는 전부 한도가 있고, 몇몇은 이미 끊겼다는 걸 이 프로젝트 자신의 문서가 증언한다. 정확한 한 줄 요약은 "Claude Code 비용을 크게 줄여주는 로컬 라우터"지, "Claude Code 공짜"가 아니다.
