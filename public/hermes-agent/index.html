Hermes Agent — 다른 PC에 깔 수 있나

Nous Research의 오픈소스 hermes-agent를 조사한다. 모델이 아니라 OpenClaw 같은 에이전트 하네스다. 결론부터: 다른 PC든 $5 VPS든 원라이너로 셋업된다. GPU도 필요 없다. 진짜 질문은 "되냐"가 아니라 "우리가 쓰는 OpenClaw에서 굳이 갈아탈 이유가 있냐"다.

00 정정 — 모델 아니라 하네스다

"Hermes"는 두 가지가 있다. (1) Nous의 오픈웨이트 LLM(Hermes 4 / 4.3), (2) 이 보고서의 주제인 hermes-agent — 오픈소스 에이전트 프레임워크. cocy가 보려는 건 후자, OpenClaw 부류의 하네스다. (모델 쪽 정리는 /hermes-local에 따로 있음.)

01 hermes-agent이 뭔가

Nous Research가 2026년 2월 MIT로 공개한 "자가개선(self-improving) AI 에이전트". 핵심 슬로건이 "the agent that grows with you" — 세션마다 리셋되는 챗봇이 아니라 자기 서버에서 상시 돌며 학습·진화하는 에이전트다. 우리가 쓰는 OpenClaw와 설계 철학·기능이 거의 겹친다(실제로 여러 매체가 "OpenClaw 대안"으로 소개).

핵심 구성

  • 상시 실행 + 영속 메모리 — VPS/홈서버/클라우드 VM에서 항상 켜진 서비스로 동작. 메시지 수신·예약작업·재부팅 후 작업 재개. 메모리는 SQLite(FTS5 전문검색)+벡터 요약 + MEMORY.md/USER.md 다층 구조. (OpenClaw랑 판박이)
  • 닫힌 학습 루프 + 자동 스킬 생성 — 복잡한 작업(멀티 툴콜) 성공하면 워크플로를 재사용 스킬(Markdown)로 자동 증류하고, 쓰면서 개선. agentskills.io 오픈 표준 호환. Honcho 변증법적 사용자 모델링.
  • 멀티플랫폼 게이트웨이 — Telegram·Discord·Slack·WhatsApp·Signal·이메일·CLU 단일 게이트웨이 프로세스. 음성메모 전사, 플랫폼 간 대화 연속성.
  • 모델 무관 — Nous Portal·OpenRouter(200+)·OpenAI·NVIDIA NIM·z.ai/GLM·Kimi·MiniMax·HF, 또는 자체 엔드포인트. hermes model로 전환, 코드 변경/락인 없음.
  • 6개 터미널 백엔드 — local·Docker·SSH·Singularity·Modal·Daytona. Modal/Daytona는 서버리스(유휴 시 하이버네이트 → 거의 무료).
  • 크론 + 서브에이전트 — 자연어 예약작업(일일 리포트/야간 백업), 병렬 워크스트림용 격리 서브에이전트, RPC로 툴 호출하는 Python 스크립트.
  • 풀 TUI — 멀티라인 편집, 슬래시 커맨드 자동완성, 대화 히스토리, interrupt-and-redirect, 스트리밍 툴 출력.
  • 툴 70+ (약 28 툴셋) — 웹검색, 브라우저 자동화, 이미지 생성, 비전 분석, 터미널 등.

02 다른 PC 셋업 — 요구사항과 절차

하네스라서 무거운 건 모델 쪽이고, 에이전트 본체는 가볍다. 모델은 외부 API로 빠지므로 설치 PC에 GPU가 필요 없다.

항목요구사항판정
OSLinux / macOS / 네이티브 Windows(WSL 불필요) / WSL2 / Android(Termux)사실상 다 됨
런타임Python 3.11 + Node.js (설치 스크립트가 uv·Node·ripgrep·ffmpeg·MinGit까지 자동 설치)자동
GPU불필요 (모델은 외부/원격 API)없어도 됨
최소 사양$5 VPS급(저사양 1코어/1GB대)에서도 구동 권장매우 가벼움
모델 키OpenRouter/OpenAI/Nous Portal 등 또는 자체 엔드포인트 1개키/엔드포인트 필요

설치 (원라이너)

Linux / macOS / WSL2:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc
hermes            # 시작

네이티브 Windows (PowerShell, 관리자 권한 불필요):

iex (irm https://hermes-agent.nousresearch.com/install.ps1)
주의 1. Windows 설치는 %LOCALAPPDATA%\hermes에, 격리된 MinGit(~45MB)을 깔아 시스템 Git을 안 건드린다. 주의 2. 백신(Defender/Bitdefender)이 번들 uv.exe(Astral의 Rust 패키지매니저)를 오탐할 수 있음 — 폴더 화이트리스트로 해결(서명 없는 Rust 바이너리 흔한 오탐).

03 우리한테 제일 중요한 포인트 — llm.cocy.io에 붙는다

hermes-agent은 "your own endpoint"를 모델 소스로 받는다. 즉 우리 llm.cocy.io(OpenAI 호환 게이트웨이)를 그대로 모델 백엔드로 꽂을 수 있다. 그러면:

  • 다른 PC에 hermes-agent만 깔고 → 모델은 llm.cocy.io 경유(클로드/gpt/제미니/로컬 라우팅 그대로 재사용).
  • 그 PC가 GPU 있으면(예: 3080 Ti) Ollama 같이 띄워 로컬 모델 + 로컬 하네스 풀 자급 구성도 가능.

04 OpenClaw vs hermes-agent — 굳이 갈아탈까

냉정하게: 기능이 거의 1:1로 겹친다. 우리는 이미 OpenClaw로 메모리·스킬·게이트웨이·크론·서브에이전트를 다 쓰고 있다. hermes-agent의 셀링포인트 대부분이 OpenClaw에도 있다.

기능OpenClaw (현재 우리)hermes-agent
영속 메모리(MEMORY/USER.md+DB)있음있음 (FTS5+벡터)
스킬(Markdown, 표준)있음 (Skill Workshop)있음 (자동생성·자가개선, agentskills.io)
멀티플랫폼 게이트웨이있음 (Telegram 등)있음 (TG/Discord/Slack/WA/Signal/메일)
크론 · 서브에이전트있음있음
모델 무관 라우팅있음 (claude-cli/google/ollama)있음 (다수 + 자체 엔드포인트)
차별점이미 우리 인프라에 정착·검증됨자동 스킬 학습 루프 강조 · 서버리스(Modal/Daytona) 하이버네이트 · Nous Portal

hermes-agent의 진짜 차별 후보는 (a) 더 공격적인 자동 스킬-증류 루프, (b) Modal/Daytona 서버리스로 유휴 시 거의 무료 정도. 나머지는 OpenClaw로 이미 커버됨.

05 결론 · 다음 액션

"다른 PC에 깔 수 있나" → 예, 아주 쉽게. 원라이너 한 줄, GPU 0, $5 VPS급. OS도 가리지 않음(네이티브 Windows 포함).

  • 그냥 평가용으로 깔아본다면 → 다른 PC에 원라이너 설치 → 모델은 llm.cocy.io 또는 OpenRouter 키 하나 → 30분 안에 손에 잡힌다.
  • 운영 전환을 고민한다면 → 권장하지 않음(아직). OpenClaw와 기능 중복이 커서, "자동 스킬 학습 루프"와 "서버리스 유휴 무료"가 우리한테 실질 이득인지부터 PoC로 확인해야 함.

제안: 1대 격리 환경(또는 그 다른 PC)에 평가 설치 → 우리 OpenClaw 스킬/메모리 운영과 비교 → 자동 스킬-증류 루프가 OpenClaw 대비 체감되는지만 본다. 어느 PC에 깔지(스펙 무관, GPU도 무관) 정해주면 설치 절차/모델 연결까지 바로 가이드한다.
