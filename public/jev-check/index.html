01 검증한 주장

원문(@choi.openai, Threads, 2026-09-16): "🚨 와.. 이건 진짜 대단한 것 같습니다. 이 가격과 속도로 판단을 맡길 수 있다면, 우리가 쓰는 프로그램에 AI를 붙이는 방식도 꽤 달라질 것 같은데요." 11장짜리 카드뉴스로 "Jev"라는 제품을 소개하며, 기존 LLM(자연어 프롬프트 → 단일 라벨 출력)과 Jev(스키마 기반 JSON 입력 → 확률 분포 출력)를 나란히 대조했다.

"Jev"가 뭔지부터 찾아야 했다.

02 실체 확인

  • TypeSafe AI가 2026-09-16 실제로 공식 발표한 신제품이다. "System One Model"이라는 새 카테고리를 자칭 — 텍스트를 생성하지 않고, 정해진 스키마 안에서 확률 분포(Noul/Choice/Score)만 병렬로 반환하는 분류·라우팅 전용 모델. 오늘 막 나온 게 맞다 — 이번 건은 날짜 재탕이 아니다.
  • 창업자 Diogo Almeida는 실존 인물이고 이력도 진짜다. 전 OpenAI 연구원, InstructGPT·RLHF 공동 개발자, ChatGPT·GPT-4 테크니컬 리포트 참여. Forbes가 "$200M 스타트업"으로 별도 취재할 만큼 주목받는 론칭.
  • 공식 가격: 입력 $0.042/백만 토큰, 출력 무료. 지연시간 70~500ms — 회사는 프론티어 LLM의 3~329초와 비교한다. 숫자 자체는 벤더가 공개한 것이라 근거는 있지만, 독립 실측은 아니다(아직 early access/waitlist라 외부 리뷰어도 실제 API 호출을 못 해봤다).
  • 문제는 홈페이지 헤드라인 "193.6배 빠름·444.6배 저렴". 독립 리뷰(Kingy AI)가 회사 자신이 공개한 반올림 벤치마크 표로 이 숫자를 재현해보려 했지만 안 됐다 — "특정 워크로드 한정 마케팅 수치로 취급하라"고 명시했다.
  • 더 결정적인 건 회사 자체 벤치마크 결과다. 4개 워크플로우 711건, 기준값은 GPT-6 Astra + Claude Fable 5.1 판정 평균(이것도 "정답"이 아니라 다른 LLM들의 의견 평균). 이 기준으로도 Jev 종합 정확도는 67.8%, 최고 비교 모델(GPT-6 Sol) 74.1%보다 낮다. 특히 인보이스 처리 항목은 격차가 크다(61.8% vs 79.1%).
  • "환각 없음(zero hallucination)" 주장은 진짜지만 좁은 의미다 — 스키마 밖 값을 낼 수 없다는 타입-세이프티 보장이지, "항상 정답"이라는 뜻은 아니다. 틀린 라벨도 스키마 안에서는 유효한 출력으로 나온다.

04 결론

Jev는 가짜 뉴스가 아니다 — 오늘 진짜 론칭했고, 창업자 이력도 진짜고, 기술 아이디어(텍스트 생성 대신 병렬 확률 헤드로 분류·라우팅만 특화)도 말이 된다. 문제는 원문 게시물의 흥분이 회사 자신이 공개한 벤치마크에서조차 Jev가 프론티어 LLM보다 정확도가 낮다는 사실(67.8% vs 74.1%)을 언급하지 않는다는 점이다. 싸고 빠른 건 진짜다. 그런데 "판단"을 통째로 맡기기엔 아직 이르다 — 고빈도·저위험 분류·라우팅의 보조 레이어로 쓰고, 정확도가 중요한 최종 결정은 여전히 프론티어 모델이나 사람 검토를 거치는 게 맞다.
