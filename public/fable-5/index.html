Claude Fable 5 — Opus 위의 새 티어

Claude Fable 5(claude-fable-5)는 Opus 위에 새로 생긴 앤트로픽 최상위 일반공개 모델이다. 2026-06-09 전 플랫폼(Bedrock 포함) GA. Messages API는 Opus 4.8과 거의 그대로인데, 딱 몇 가지 — thinking:disabled 제거, adaptive 사고 항상 on, 거부/폴백 흐름 추가 — 가 다르다. 가격은 정확히 2배.

01 무엇인가

Fable 5는 앤트로픽이 "가장 까다로운 추론·장기 에이전트 작업"용으로 내놓은 가장 강력한 일반공개 모델이다. 기존 명명(Opus/Sonnet/Haiku)과 별개의 상위 티어 이름으로 출발했다.

  • 형제 모델 Mythos 5(claude-mythos-5) — Fable 5와 동일 능력에서 안전 분류기만 뺀 버전. 일반공개 아님(초대제 Project Glasswing). Mythos Preview의 후속.
  • 플랫폼 — Claude API · Claude Platform on AWS · Amazon Bedrock · Vertex AI · Microsoft Foundry 전부 6/9 GA. (Bedrock ID는 접두사 붙어 anthropic.claude-fable-5.)
  • 데이터 보존 — Covered Model로 지정 → 30일 보존 고정, 무보존(ZDR) 불가. 컴플라이언스에 민감한 워크로드는 확인 필요.

SWE-Bench Pro는 GitHub 이슈 기반 실코딩 벤치마크. Fable 5는 Opus 4.8보다 +11.1%p, GPT-5.5보다 +21.7%p 높다. 앤트로픽은 소프트웨어 엔지니어링·지식 작업·비전·과학 연구 전반에서 거의 모든 AI 역량 벤치마크 최상위라고 발표했다.

  • 토큰 효율 주의 — Opus 4.7 토크나이저라 같은 글이 이전 모델보다 ~30% 더 토큰을 먹는다. "출력 단가 2배 × 토큰 수 증가"가 곱해지므로 체감 비용은 단순 2배 이상일 수 있다.
  • 장기 에이전트 — 몇 주에 걸친 대규모 코드 마이그레이션·다단계 비동기 작업을 자율 처리하는 사례가 보고됨. 우리처럼 에이전트 루프가 많은 스택에선 "어려운 1건"에서 격차가 나올 수 있다.

05 우리 스택 시사점 (openclaw / cocy)

우리는 이미 Fable 5를 openclaw에 추가했다(별칭 fable → anthropic/claude-fable-5, claude-cli 런타임). 운영 관점 정리:

  • 기본 모델은 그대로 Opus 4.8. 출력 $50/MTok은 우리처럼 툴콜·장기 세션이 많은 에이전트엔 부담. Fable은 "가장 어려운 1건"에만 선택적으로 쓰고, 일상 작업은 4.8 유지가 ROI상 합리적.
  • 한국어 비용이 곱으로 쌓인다. 우리가 측정한 한국어 토큰 페널티 + Fable의 토크나이저(~30%↑) + 단가 2배 → 한국어 장문 작업에서 비용이 빠르게 커진다. 모델 라우팅 시 1순위 고려.
  • 거부/폴백 흐름은 인프라적으로 유용. fallbacks 파라미터 + 폴백 크레딧은 "Fable 거부 시 4.8로 자동 강등 후 캐시비 환급" 패턴을 표준 지원. 우리 openclaw는 이미 폴백 리스트(gpt-5.4)가 있으니, Fable 라우팅 시 refusal(HTTP 200) 분기만 점검하면 된다.
  • 설정 호환성 1줄 점검. 어딘가 thinking:disabled를 박아둔 곳이 있으면 Fable에서 400. 우리 게이트웨이는 claude-cli 런타임으로 돌아 일반적으로 무관하나, 커스텀 호출부가 있으면 "끄기 = 생략"으로 확인.
  • Mythos 5(안전분류기 제거판)는 우리 대상 아님 — 초대제. 인지만 해두면 됨.

06 유의점

  • 출시 직후(2026-06-09) 모델이라 실사용 벤치/회귀 데이터가 아직 얇다. 도입 전 우리 워크로드로 소규모 A/B 권장.
  • Covered Model = 30일 데이터 보존 고정, ZDR 불가 — 민감 데이터 파이프라인이면 확인.
