로컬 Laya가 OpenAI Decisions API를
이겼다?

atomic.chat 계정이 "M5 Max에서 로컬로 돌린 Laya가 OpenAI의 결정 API를 이겼다"는 영상을 올렸다. 트윗 본문, OpenAI 공식 문서, Laya 모델 카드와 저장소, 제3자 벤치마크를 확인해 "이겼다"가 무엇을 근거로 하는 말인지 따져봤다. 직접 비교 실험은 돌리지 않았고, 영상도 보지 못했다.

점수는 "주장이 말하는 것을 그대로 믿어도 되는가" 기준이다. 속도 방향성 자체는 맞아 보여서 낮게 주지는 않았고, 정확도 근거 없이 "이겼다"고 말한 점과 조건이 다른 비교라는 점에서 4점으로 깎았다(평가).

1. 무엇을 주장했나

트윗은 "Local Laya beat OpenAI's decision API"라고 쓰고, 결정 모델 4개가 웹 페이지를 내려가며 "거미(spider)를 언급하는 링크"를 뽑아내는 경주를 했다고 설명한다. M5 Max에서 로컬로 돌린 Laya는 링크당 34ms가 걸려 클라우드 모델보다 3배 더 많이 검사했다는 것이다. 트윗 끝에는 "Run decision models locally"라는 atomic.chat 제품 안내가 붙어 있어 홍보 성격의 시연이다. 과제는 키워드성 필터에 가까워 어려운 판단이 아니고, 맞고 틀림을 채점한 정보도 없다. 29초짜리 영상이 붙어 있는데 이 영상은 보지 못했다. 아래 분석은 트윗 본문과 공개 문서에 근거한다.

2. OpenAI Decisions API는 무엇인가

  • 2026-10-06에 공개 베타로 나왔다. 지원 모델은 GPT-6 Luna뿐이고 입력 100만 토큰당 $0.10이다.
  • 공식 문서의 "약 10배 빠름"은 같은 작업을 Responses API로 풀었을 때와의 비교다. 절대 지연시간 보증이 아니다.
  • 텍스트, 이미지(인라인 base64만 지원), 또는 둘 다 받는다. 입력 토큰에만 과금하고 출력·캐시 요금은 없다.
  • OpenAI 커뮤니티 공지 스레드에는 사용자 후기가 몇 개 있다. 한 명은 Jev와 비교해 Luna에서 개선을 못 봤다고 했고, 다른 한 명은 쉬운 판정에서는 둘이 비슷하고 Luna가 조금 더 자주 맞지만 확신도 보정은 조금 덜하다고 적었다. 개인 테스트라 근거로 쓰지는 않았다.

3. Laya는 무엇인가

  • Convai Innovations가 만든 ModernBERT-large 기반 421M 오픈웨이트 모델(Apache 2.0). 글을 생성하지 않고, 상태와 질문을 넣으면 선택·점수·예/아니오의 확률을 돌려준다.
  • 모델 카드는 약 33ms 추론을 적고, Ollama 페이지는 M5 Max에서 질문당 10ms 미만이라고 적는다.
  • 같은 모델 카드가 자체 typed-decisions 벤치에서 zero-shot 0.362, 파인튜닝 체크포인트 0.766이라고 밝힌다. 파인튜닝 없이는 실사용 정확도가 아니라는 뜻이다.
  • 우리가 직접 돌려본 zero-shot 결과도 같은 방향이었다. 텔레그램 메시지 147개로 프롬프트 라우팅을 시켰더니 18~44%로 정규식 20줄(62%)보다 낮았고, 한국어 확신도 보정 오차(ECE)는 0.246이었다.

비교의 한계benchlm은 공유 행이 2개뿐이라 종합 승자를 지목하지 않는다고 명시종합 점수이고 속도·비용 축이 섞여 있음

JevBench는 제3자(Benchmark Heaven)의 벤치마크로, 정확도·보정·속도·비용을 같은 비중으로 합산한다. 그래서 위 점수는 순수 정확도가 아니라 종합 점수다. 그래도 속도가 빠른 로컬 모델이라는 Laya의 장점이 이미 반영된 점수에서 뒤진다는 점은 "이겼다"는 서술과 어긋난다. 같은 벤치의 이전 측정에서 TypeSafe의 Jev도 공개 문항 86.6%에 비해 비공개 문항 36.7%로 크게 떨어졌고, GPT-6 Luna(low)는 비공개 문항에서 92.9%를 냈다는 기록이 있다(v1.4.1 기준, 우리가 이전에 확인한 값이며 이 글에서 다시 열어보지는 않았다).

결론

로컬 소형 모델이 클라우드 왕복보다 빠른 것은 사실에 가깝고, 이 점에서 Laya 같은 결정 모델의 의미는 있다. 하지만 이 트윗이 보여준 것은 "더 빠르다"이지 "더 낫다"가 아니다. 판정 작업은 틀린 답이 빨리 나오는 것이 이득이 아니어서, 같은 문항으로 정확도와 지연, 비용을 함께 잰 비교가 나와야 "이겼다"를 말할 수 있다. 그런 비교가 공개되면 점수를 다시 매길 수 있다.
