CASE FILE · KR-VOICEPHISHING-2026 · ON-DEVICE VOICEPRINT LAB

그놈 목소리

지금 전화기 너머 그 목소리 — 등록된 그놈입니까?
금융감독원·경찰이 공개한 실제 보이스피싱 사기범 음성 6건의 성문(聲紋)을 추출해, 브라우저 안에서 내 녹음과 직접 대조합니다.

EVIDENCE
성문+운율+내용 3중 분석 온디바이스 — 녹음 미전송 ECAPA-TDNN · 192-dim int8 ONNX 21MB
EXHIBIT 01

사기범 성문 DB

공개된 실제 사기범 음성에서 화자분리로 사기범 발화 구간만 추출해 성문을 등록했다. ▶ 를 눌러 직접 들어보라. 전부 검사·수사관 사칭 수법이다.

EXHIBIT 02

성문 대조 실험

실험 A — 그놈 목소리 들려주기 위 샘플 하나를 다른 기기(또는 이 폰 스피커)로 재생하면서 녹음해보라. → 해당 사기범 유사도가 임계선을 넘는다
실험 B — 내 목소리 평소 통화하듯 아무 말이나 6초. 이름·번호 같은 개인정보는 말하지 말 것. → 정상이라면 전원 임계선 아래
FEATURE RADAR ·

성문(음색)이 낮아도 음높이·억양·리듬이 함께 높으면 변조 의심 신호다. 오른쪽 막대를 누르면 다른 사기범 축으로 전환.

VOICEPRINT MATCH · 성문 일치도
CONTENT ANALYSIS · 통화 내용

성문 유사도 = ECAPA 벡터 코사인, 0.65 이상이면 동일 화자 의심(전화대역 기준 실측 캘리브레이션). 운율 4축(음높이·억양 폭·리듬·페이스)은 녹음과 사기범 클립 양쪽을 같은 코드로 측정해 비교한다. 내용 분석(STT)은 브라우저 내장 음성인식을 쓴다 — 크롬 등 일부 브라우저는 인식 처리를 위해 음성을 브라우저 제공사 서버로 보낼 수 있다. 토글을 끄면 완전 온디바이스로만 동작한다. 이 수치는 데모용이며 법적 판단 근거가 아니다. 성문·운율 분석용 녹음은 분석 후 즉시 폐기되고 어디로도 전송되지 않는다.

EXHIBIT 03

어떻게 저장하고 대조하나

음성 파일을 그대로 저장·비교하는 게 아니다. 목소리의 결을 192개의 숫자로 압축한 성문 벡터만 저장한다 — 지문처럼, 원본 복원은 불가능하지만 대조는 가능한 형태다. 여기에 화자 습관이 담기는 운율 특징(음높이·억양·리듬·페이스)을 함께 측정한다.

공개 음성 수집금감원 '바로 이 목소리'·경찰 공개 자료에서 원본 확보
화자 자동 분리3초 창으로 잘라 임베딩 후 군집화 — 내레이터·피해자를 걸러내고 사기범 발화만 선별
전화대역 정합모든 음성을 300–3,400Hz 전화 대역으로 통일 — 채널 차이가 아니라 목소리 차이만 비교
성문 인코딩ECAPA-TDNN(화자인식 표준 모델)으로 192차원 벡터화, int8 양자화로 21MB
운율 측정F0 추적(YIN)·음절률·발화 비율을 브라우저에서 직접 계산 — 변조에도 남는 말버릇 축
온디바이스 대조브라우저 WASM으로 내 녹음을 같은 방식으로 인코딩 → 코사인 유사도. 서버 없음
등록 성문 6건의 상호 유사도 (실측)

서로 다른 사기범끼리는 0.23~0.58에 머문다. 즉 이 성문 공간에서 6명은 뚜렷이 구분되며, 같은 화자의 새 녹음이 들어오면 해당 행만 0.65 이상으로 튀는 구조다.
