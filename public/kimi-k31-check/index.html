Kimi K3.1 Pro,
AA 4위에 가격은 절반?

Threads(@choi.openai)에 11편짜리 글이 돌고 있다. "Moonshot의 Kimi K3.1 Pro가 Artificial Analysis 종합 4위, 1위 Opus 5.5와 3점 차인데 가격은 절반, 가중치는 11월 4일에 푼다." Moonshot 공식 블로그, Hugging Face 모델 카드·라이선스, Artificial Analysis 페이지를 직접 대조했다.

종합 순위와 가격 비교는 1차 출처와 일치한다. 다만 스레드는 K3.1이 이기는 영역만 보여주고, 크게 지는 영역(프로그램 재구현, 무도구 추론, 사이버)과 "토큰을 많이 쓰는 모델"이라는 비용 맥락을 다루지 않았다. "가중치 공개"도 아직 일어나지 않은 일이다.

2. 모델 개요 — 이건 주장대로다

  • K3.1 Pro는 K3를 후속 학습(post-training)한 버전이다. 2.8T 파라미터 MoE, 활성 104B, 컨텍스트 1M, 텍스트·이미지 입력.
  • K3.1 시리즈는 2–3배 빠른 Highspeed 변형과 함께 나왔다.
  • Moonshot은 가중치를 "2026-11-04까지" 공개하겠다고 밝혔다. 지금 받을 수 있는 건 K3까지다.

읽는 법: 도구를 쓰는 에이전트 작업(웹 탐색, 사무 자동화, 장기 SWE)에서는 Opus 5.5와 비슷하거나 앞선다. 도구 없이 순수 추론으로 푸는 시험(HLE 무도구), 바이너리를 통째로 재구현하는 ProgramBench, 공격 코드 작성은 확실히 뒤진다. 그래서 "종합 3점 차"는 평균이고, 용도에 따라 체감 격차가 크게 달라진다.

4. 벤치마크를 믿어도 되나

  • 자체 보고. 표 전체가 Moonshot 발표치다. Kimi 점수는 Claude Code 하니스, 최대 추론 강도로 돌렸고, 경쟁 모델 점수는 각 벤더 발표치나 리더보드에서 가져왔다. 일부는 블로그에 "fallback" 동작이 표기돼 있다. 조건이 완전히 같다는 보장이 없다.
  • AA 지수는 독립 측정이다. 55점·4위·비용은 Moonshot이 아니라 AA 수치라서 신뢰도가 더 높다. 스레드의 핵심 숫자가 여기서 나온 건 맞다.
  • 부정행위 처리. 블로그에 따르면 실행 중 정답을 온라인에서 찾아온 경우는 0점 처리했다. 이 부분은 검증 가능한 기준으로 공개돼 있다.
  • 환각 벤치마크는 내부용. Kimi Hallu Bench는 Moonshot 자체 시험이고, 블로그도 스트레스 테스트로 설명한다. 이 수치(낮을수록 좋음, Kimi 5.4 vs Opus 6.8)를 "환각 적다"의 근거로 쓰기엔 약하다.

5. 라이선스 — 오픈이지만 무조건은 아니다

Kimi K3 라이선스(HF 저장소의 LICENSE 원문 확인)는 MIT 계열로 허용 범위가 넓다. 조건은 두 가지다.

  • MaaS 제한: 모델을 API 서비스로 재판매하는 사업이 연 매출 $2,000만을 넘으면 별도 계약이 필요하다.
  • 표기 의무: 월간 활성 사용자 1억 명 초과 또는 월 매출 $2,000만 초과 제품은 "Kimi K3"를 표시해야 한다.

사내 사용, 그리고 Moonshot 공식 제품이나 인증 파트너를 통한 사용은 예외다. 개인·스타트업이 자체 서버에서 쓰는 데는 사실상 제약이 없다. 단, 이건 K3 라이선스 기준이고 K3.1 가중치가 같은 조건으로 나올지는 공개 전까지 확인할 수 없다.

6. 사이버 능력은 일부러 깎았다

블로그에 따르면 Moonshot은 중간 학습과 RL 단계에서 사이버 관련 데이터를 제거했다. 내부 벤치마크 xdev-bench-hard가 90.5에서 81.0으로 내려간 것이 그 결과다. 같은 방향으로 ExploitBench·ExploitGym에서도 Opus 5.5, GPT-6 Astra보다 낮다. 오픈 가중치 공개를 앞둔 안전 조치로 읽히지만, 이 해석은 블로그 설명에서 추론한 평가다.

검증하지 못한 항목

  • 스레드가 인용한 AA Terminal-Bench 수치(67%, K3 13%)와 Code Arena 순위
  • Sonnet·Muse 계열 56점 비교, WIRED 기사 인용

이 항목들은 AA 페이지 렌더링 한계와 검색 도구 장애로 독립 재확인하지 못했다. 위 판정에는 포함하지 않았다.

결론 — 쓸까?

에이전트형 작업(웹 탐색, 사무 자동화, 장기 코딩)에 Opus급 성능이 필요하고 비용이 민감하다면 시험해볼 가치가 높다. AA 기준 작업당 비용이 약 1/3이고, 가중치가 풀리면 자체 호스팅 선택지도 생긴다. 반대로 프로그램 재구현, 도구 없는 고난도 추론, 보안 작업이 주 용도라면 Opus 5.5가 확실히 앞선다. 토큰을 많이 쓰는 모델이라 실제 청구액은 작업 유형에 따라 AA 수치와 달라질 수 있으니 내 워크로드로 직접 재야 한다.

스레드에서 가져갈 건 "55점·4위·3점 차·저렴하다"까지다. "11/4 공개"는 "11/4까지 공개 예정"이고, "3점 차"는 종합 평균일 뿐 영역별 격차는 훨씬 크다.
