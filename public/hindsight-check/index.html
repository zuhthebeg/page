Hindsight,
진짜 쓸만한가

X에서 Hindsight(vectorize-io/hindsight)라는 에이전트 메모리 프레임워크를 "리버스 엔지니어링해서 공개했다"는 글이 돌았다. 스타 4만 개가 넘는 레포이고 벤치마크 점수도 높다고 한다. 링크만 훑지 않고 직접 설치해서 한국어 사실 6개를 저장(retain)하고 6개 질의로 검색(recall)해봤다. 결론부터: 쓸 수 있다. 다만 트윗이 말하는 것보다 무겁고, 숫자는 자기들이 잰 것이다.

에이전트 메모리직접 설치 테스트벤치마크 검증한국어

7/10판정: 실존하고 동작한다. 홍보 문구는 걸러서 읽어라.
✓ MIT 라이선스, 활발한 커밋, 논문과 주간 릴리스가 있는 실제 프로젝트 ✓ 한국어 저장·검색·시간 질의가 실제로 동작함 (직접 확인) △ "리버스 엔지니어링"은 1년 된 자기 제품 홍보에 붙인 수사 △ "독립 재현"은 논문 공저자들이 한 것, 경쟁사 점수는 다른 벤더 리더보드에서 가져옴 ✗ 14억 토큰 처리 같은 규모 주장은 확인 불가 ✗ 설치가 무겁고(6.3GB), 저장할 때마다 LLM 호출이 든다

제품 자체는 진짜고 아이디어도 괜찮다. 감점 요인은 세 가지다. 트윗 작성자가 이 프로젝트의 핵심 개발자라는 점, 벤치마크 비교가 사실상 자체 심판(GPT-OSS-120B)과 복사한 경쟁사 점수 위에 서 있다는 점, 그리고 설치·운영 비용이 "메모리 한 겹 얹기" 수준이 아니라는 점이다.

1. 프로젝트는 진짜다

먼저 인정할 것: 허공의 프로젝트가 아니다. GitHub에서 확인되는 사실은 이렇다.

  • vectorize-io/hindsight, MIT 라이선스, 스타 약 4.7만 개(2026-10-08 확인), 주간 단위 릴리스가 이어지고 있다.
  • 서버, 여러 언어 SDK, MCP 서버, 각종 프레임워크 연동이 레포에 같이 들어 있다.
  • 구조는 네 가지 기억 네트워크(세계 사실, 경험, 관찰, 멘탈 모델)와 세 연산(retain 저장, recall 검색, reflect 성찰)이다.
  • recall은 의미 검색, BM25, 그래프, 시간 검색을 RRF로 합친 뒤 크로스 인코더로 재순위한다. 저장소는 PostgreSQL+pgvector(내장 pg0도 가능)이고 LLM 제공자는 설정 가능하다.

2. 트윗 문구를 걸러서 읽기

트윗/홍보의 주장확인한 것판정
"리버스 엔지니어링해서 공개"작성자는 이 레포의 핵심 개발자(커밋 약 1,900개), Vectorize 소속 리드 엔지니어. 남의 걸 뜯은 게 아니라 자기 제품을 소개한 글수사
"독립적으로 재현"재현한 쪽이 논문 공저자들. 독립 검증이라 부르기 어렵다과장
벤치마크 고득점(LongMemEval·LoCoMo 등)비교 대상 점수는 다른 벤더 리더보드에서 가져온 값, 채점자는 GPT-OSS-120B. 나는 이 숫자를 재현하지 않았다미검증
14억 토큰 처리공개 근거를 찾지 못했다확인 불가
오픈소스 메모리 프레임워크MIT, 코드·서버·SDK 전부 공개사실

3. 직접 돌려봤다

WSL에 설치해서 한국어 사실 6개를 저장하고, 6개 질의로 검색했다. LLM은 OpenAI Codex 로그인(gpt-5.5)을 붙였다. 표본이 6개라서 벤치마크가 아니라 "굴러가는지"를 보는 스모크 테스트다.

  • 동작함. 한국어 저장과 검색 모두 정상이고, "언제" 류의 시간 질의도 맞게 풀었다.
  • 속도. 저장 한 건에 약 2.5초(LLM 추출이 끼기 때문), 검색은 0.5~1.2초.
  • 순위 흔들림. 한국어 질의 "배포할 때 순서는?"은 정답 사실이 8~9번째로 밀렸다. 같은 사실을 영어 키워드로 물으면 1위였다. 최근에 저장한 무관한 사실이 위로 올라오는 최신성 편향도 보였다.
  • 중복. 원문과 정제본이 같이 반환돼서 결과 목록이 부풀었다.
무게 경고
가상환경이 6.3GB였다(CUDA 라이브러리 포함). 저장할 때마다 LLM 호출이 들기 때문에 비용과 지연이 쓰는 만큼 따라온다. 마크다운 파일에 검색 한 겹을 얹은 정도의 가벼운 도구가 아니다.

4. 쓸만한가

쓸 만하다. 에이전트가 여러 세션에 걸쳐 사용자 사실을 쌓아야 하고, 시간 관계까지 물어야 하는 제품이라면 직접 만드는 것보다 이걸 얹는 편이 빠르다. 반대로 마크다운 메모리와 키워드·벡터 검색으로 충분한 개인 에이전트에는 과하다. 도입한다면 교체가 아니라 작은 파일럿으로 시작하는 걸 권한다. 한국어 질의 순위가 흔들린 점은 실제 데이터로 한 번 더 재볼 것.

확인하지 못한 것: 91%대 벤치마크 수치, 14억 토큰 주장, 운영 규모에서의 성능, OpenClaw 같은 에이전트 런타임과의 실제 연동.
