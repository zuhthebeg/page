NVIDIA가 AI 모델 140개를 1년간 공짜로 준다는데, 진짜야?

X(트위터)에서 6.8만 조회수 넘게 퍼진 주장을 직접 검증했습니다. NVIDIA 공식 문서, 실사용자 답글, 실측 요금정책을 대조한 결과: 존재는 진짜, 톤은 과장입니다.

종합 판정 3 / 5 반은 사실, 반은 과장

✓ 사실로 확인된 부분

  • build.nvidia.com(NIM 카탈로그)은 실재한다. GLM, MiniMax, DeepSeek, Nemotron 등 80~100개+ 모델을 API로 무료 제공하는 건 사실.
  • OpenAI API 호환. base_url만 바꾸면 기존 클라이언트·SDK 그대로 쓸 수 있음 — 원 트윗 주장과 일치.
  • 가입 시 무료 크레딧 지급. NVIDIA Developer Program 가입하면 기본 1,000크레딧, 요청 시 최대 5,000크레딧까지 받을 수 있음.

! 과장·오해 소지가 있는 부분

  • "1년간 무료" 보장은 NVIDIA 공식 문서 어디에도 없다. 실제 표기는 "개발·테스트·평가용(prototyping, development, testing, research, evaluation)" — 기간 제한이 아니라 용도 제한이다.
  • "루프 돌려도 비용 0"은 사실과 다르다. NVIDIA는 이 무료 티어를 명시적으로 "프로덕션 워크로드 대상 아님"이라고 못박아둠. 실측 rate limit은 대략 40RPM 안팎(모델·트래픽에 따라 변동, 공식 SLA 아님).
  • 실사용자 체감은 훨씬 나쁘다. 원 트윗 답글에서 직접 확인된 반응: "1분에 1요청, 429 에러 계속"·"레이턴시 심각"·"에이전틱 용도로 쓰기엔 너무 제한적".
  • 리스트에 있다고 다 되는 것도 아님. 같은 답글 스레드에서 "GLM-5.2는 아직 무료로 안 풀렸다"는 언급 확인.

→ 그래서, 실제로 쓸만한가

존재 자체는 진짜고 크레딧도 실제로 준다. 근데 상시 호출하는 에이전트 파이프라인·프로덕션 서비스엔 안 맞는다 — NVIDIA 스스로 그 용도가 아니라고 명시했고, 실측 레이트리밋도 그걸 뒷받침한다.

적당한 용도: 새로 나온 오픈모델(GLM, MiniMax 등) 성능을 배포 인프라 없이 몇 번 찍어보는 것. 안 맞는 용도: 유료 API 구독을 대체하는 상시 워크로드.
