# PG1 — 요청 분류기

## Design context (브리프 기준)
- 독자: LLM 게이트웨이 경로와 장애 경계를 이해하려는 한국어 독자.
- 작업: 같은 요청을 다른 경로에 투입하고, 실패·전원·인증 상태를 조작해 결과를 비교.
- 톤: cocy 소유 분석 해설. 종이 위의 정밀한 산업용 분류기, 과장 없는 조작 실험.

## Figure / 원본 제작
하나의 요청 캡슐이 인증 셔터를 지나 세 갈래 레일로 분류되고, 실패 시 예비 레일로 딱 한 번 우회한다.
등각 투영(45°/30°)으로 직접 작성한 SVG. 라이브러리·원본 예제 코드는 복사하지 않는다.
상태 모델이 레일 선택·기계 셔터·캡슐 이동·결과·접근성 텍스트를 함께 결정한다.

## 부품 목록 (40개 이상)
- 바닥: 두께 있는 베이스, 다리 4개, 각 다리 받침 4개, 베이스 체결 나사 4개.
- 구조: 투입 홈통, 인증 셔터 레일 2개, 인증 셔터, 분류기 하우징, 회전 선택판, 선택판 나사 4개.
- 기구: 3개 출력 레일 각각 바닥/양측 벽/롤러 6개/출력 받침, 실패 분기 레일, 예비 레일, 단일 회전 래칫, 역진 방지 톱니, 정지 셔터.
- 조작: 라우터 손잡이, 래칫 축, 전원 차단 브리지, 셔터 스프링, 레일 고정구.
- 주제: 주황 요청 캡슐 1개. 장식 기어가 아니라 경로 전환과 정지를 실제로 가시화.

## 설명 모델의 경계
실제 서비스의 모든 오류·과금 정책을 재현하지 않는다. 모델 이름은 API 모델/구독 모델/로컬 모델이라는 공개 개념만 사용.
데모의 예비 모델은 PC가 필요한 경량 구독 CLI로 정의. 정상 API는 PC가 꺼져도 성공. API가 실패하면 이 예비 경로는 PC 전원이 필요하다.
인증 실패는 라우터 이전 차단. 실패/PC 차단 모두 예비 경로를 최대 1회만 확인. 예비 실패 시 추가 API 과금 경로로 전환하지 않고 정지.
시간·처리량·가격 수치 없음. 애니메이션 길이는 연출 시간이며 실제 지연이 아님.
GTM/SEO/AdSense는 브리프대로 적용하며 시뮬레이터는 네트워크 호출을 하지 않는다. GTM 자체의 분석 요청과 모델 요청을 구분.
